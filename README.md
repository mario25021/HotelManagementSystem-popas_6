# Hotel Management System

A simple Java console application for managing hotel rooms and reservations.

## Features

- Display all hotel rooms and their details
- Search for a room by room number
- Reserve and release rooms
- Display available rooms
- Count the total number of rooms
- Search for rooms by type
- Calculate the cost of a stay based on the room price and number of nights

## What I Practiced

I built this project to improve my Java programming skills and practice object-oriented programming.

While working on it, I practiced:

- Classes and objects
- Constructors and constructor overloading
- Methods and arrays
- Conditional statements and loops
- Working with user input using `Scanner`

## Technologies

- Java
- IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java is installed.
4. Run `Main.java`.
